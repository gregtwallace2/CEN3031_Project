# CEN3031_Project - Student Loan Calculator

## Installation

This project requires Node.js version 20.19+ or 22.12+. 22.20+ is recommended.

1) Install Node.js
2) Clone this repo locally.
3) Run `npm i` (npm is installed with Node.js) to acquire all of the necessary dependencies.

## Running the App

1) `npm run dev` starts a local development build.
2) Open your browser and navigate to `http://localhost:5173/` to view the application.
